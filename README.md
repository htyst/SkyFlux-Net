# SkyFlux-Net · HELIO LAB P10

面向空间天气研究的本地 P10 高能质子通量预测演示系统。提供 CSV 数据导入、五种时间尺度的模型推理、观测与预测曲线、告警阈值显示和结果 CSV 导出。

## 本地运行

需要 Windows 和 64 位 Python 3.10–3.12，无需 Node.js 或 GPU。

1. 克隆或下载本仓库。
2. 双击 `安装依赖.bat`，创建项目内的 `.venv` 并安装依赖。
3. 双击 `启动网站.bat`，等待出现 `P10 forecast site is ready`。首次加载 PyTorch 可能需要约一分钟，服务就绪后会自动打开浏览器。
4. 访问 <http://127.0.0.1:8765/>，点击“载入历史示例”验证五个模型。

使用期间保持启动窗口打开，按 `Ctrl+C` 停止服务。重启电脑后需要重新启动网站，无需重复安装依赖。

已有项目虚拟环境时，可在仓库根目录的 PowerShell 中启动：

```powershell
& '.\.venv\Scripts\python.exe' -u server.py --open-browser
```

其他系统可使用已安装依赖的 Python 运行 `python server.py`。仅预览页面布局可使用 `只看前端.bat`，地址为 <http://127.0.0.1:8766/>，该模式不提供预测接口。

## 数据与模型

- 支持 `5min`、`1h`、`2h`、`1d`、`3d` 五种尺度，模型权重位于 `models/`。
- CSV 必须包含 `datetime,bulkspeed,kp,e2,p1,p10`，输入原始数值，不要预先取对数或标准化。
- `samples/` 提供历史示例。上传这些数据时，请勾选“历史数据演示”；单尺度示例还需选择对应尺度。
- `static/` 是无需构建的前端源码；`server.py` 提供本地 HTTP API，`forecast_core.py` 实现预处理和模型结构。
- `reference_media/` 包含宣传片和封面，运行网站不依赖这些文件。

详细说明见 [运行与交接说明](README_先看.md)、[接口约定](docs/接口约定.md)和[页面与开发说明](docs/页面与开发说明.md)。

## 使用边界

本项目是本地研究原型。模型使用截至 2025 年 2 月的历史数据训练，多个短时尺度在独立测试集上未超过持续性基线。尚未接入实时数据，不应将历史演示结果用于正式预报或预警。

虚拟环境、Python 缓存和运行日志不纳入版本管理。下载项目后需在本机安装依赖。
