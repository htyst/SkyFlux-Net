# HELIO LAB · P10 预测网站交接包

本包供同学在本机运行、修改和继续集成网站。`static/` 是完整前端源码；`server.py`、`forecast_core.py`、`models/` 和 `samples/` 是与当前页面配套的本地推理服务，放在同一包里，方便直接复现上传 CSV → 预测 → 图表 → 导出 CSV 的流程。

## 先运行

1. 在 Windows 电脑安装 **64 位 Python 3.10–3.12**，安装时勾选加入 PATH。
2. 双击 `安装依赖.bat`。它会优先选择本机可用的 Python 3.12、3.11 或 3.10，在本文件夹创建 `.venv` 并安装 PyTorch、NumPy、Pandas、scikit-learn；首次安装需要网络，PyTorch 下载可能较大。
3. 双击 `启动网站.bat`。加载依赖时会显示进度提示，首次加载 PyTorch 可能需要约一分钟；出现 `P10 forecast site is ready` 后会自动打开 <http://127.0.0.1:8765>。保持命令窗口打开，按 `Ctrl+C` 可停止。
4. 点“载入历史示例”验证五个模型；或选择“单尺度数据”，上传 `samples/1h.csv`，勾选“历史数据演示”，点击“运行预测”，最后点击“导出结果 CSV”。

若已有安装上述依赖的 Python 环境，也可在本目录直接运行 `python server.py`。服务默认只监听本机 `127.0.0.1:8765`，推理使用 CPU，无需 GPU。

### 已安装环境但网页打不开

- 安装依赖后仍需启动服务；只打开网址不会自动启动 Python。启动期间请等到 `ready` 提示再刷新页面。
- 优先使用 `启动网站.bat`，它固定使用本目录的 `.venv`，不依赖系统默认 Python 或当前激活的 Conda 环境。
- 在 PowerShell 中手动启动时，先进入本文件夹，再运行 `& '.\.venv\Scripts\python.exe' -u server.py --open-browser`。
- 若提示端口已占用，先访问上述网址确认是否已启动；如果是其他程序占用，请停止相应程序后重试。关闭服务窗口后网址将无法访问，下次使用需要重新启动。

已在 Windows、Python 3.10.20、NumPy 2.2.6、Pandas 2.3.3、scikit-learn 1.7.2、PyTorch 2.11.0 环境验证。`requirements.txt` 允许兼容版本；如果后续升级后出现模型加载问题，先按这组版本排查。

只想看页面布局时，可以双击 `只看前端.bat`，访问 <http://127.0.0.1:8766>。此模式只使用 Python 标准库，**不提供预测 API**；模型状态、历史示例和“运行预测”需用完整服务。

## 文件怎么分工

| 路径 | 用途 |
| --- | --- |
| `static/index.html` | 页面结构、文案、表单及结果区域 |
| `static/styles.css` | 主题色、布局、动画、响应式样式 |
| `static/app.js` | 文件读取、API 请求、结果卡片、SVG 曲线、CSV 导出 |
| `server.py` | 本地 HTTP 服务，处理 CSV 和三个 API |
| `forecast_core.py` | 特征预处理、时间检查、模型结构 |
| `models/*.pt` | 五个已训练模型，约 2 MB |
| `samples/*.csv` | 五种时间尺度的历史演示输入 |
| `docs/接口约定.md` | 前后端数据格式与错误处理 |
| `docs/页面与开发说明.md` | 页面结构、修改入口、交接注意事项 |
| `docs/demo_response.json` | 当前真实模型运行历史示例后的响应快照，仅作开发参考 |
| `reference_media/` | 宣传片和封面，仅作视觉与操作流程参考，网站运行不依赖 |

页面没有 npm 构建步骤、外链字体或远程图床。`static/` 三个文件可直接修改，刷新浏览器即可看到变化。前端使用同源相对接口路径，若日后单独部署前端，请用代理把 `/api/*` 转发给后端，或修改 `static/app.js` 的请求地址。

## 输入与结果

- CSV 必需列：`datetime,bulkspeed,kp,e2,p1,p10`；列顺序不限。时间戳示例：`2025-02-21 04:00:00`。数值填原始单位，**不要先取对数或标准化**。
- “五分钟数据 · 多尺度”需要连续五分钟数据，服务端只聚合完整区间；数据不足时各尺度会返回明确原因。“单尺度数据”可直接上传相应尺度的 CSV。
- 时间列无时区偏移，页面需选 UTC 或北京时间。历史样本要勾选“历史数据演示”；正式输入会检查时间是否过期。
- 结果是下一时间段的 P10 通量，单位 pfu。页面显示模型值、持续性基线、黄/橙/红告警阈值（10/100/1000 pfu）、历史趋势，并可导出结果 CSV。

## 目前的边界

这是**本地研究原型**。模型基于截至 2025 年 2 月的历史数据训练，多个短时尺度在独立测试集上未超过持续性基线。未接入实时数据和图像融合，不可把演示画面当作实时预报或正式预警。宣传片中的结果来自历史样本和已训练模型。

交给同学时，建议一并说明：网站可运行，但后续上线需要确定实时数据源、模型评估标准、服务器部署和访问控制。不要把 `.venv/`、用户上传的 CSV 或临时文件提交到公开仓库。
